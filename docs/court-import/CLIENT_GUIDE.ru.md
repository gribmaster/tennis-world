# Импорт кортов из PDF — инструкция для администратора

Эта инструкция для того, кто добавляет новые корты через ИИ-агента, без
программирования. Все данные о кортах уже есть в **PDF-файле с карточками
кортов** (одна страница на корт): агент только переносит их в файл для импорта.

## Что нужно подготовить

1. **PDF с карточками кортов** в том же формате, что и «The Tennis Map — Court
   Cards»: на первой странице список кортов («In this file»), дальше по одной
   странице на корт с названием, городом и страной, координатами, метками,
   блоком «The Essentials», описанием и кнопкой «Open in Google Maps».
2. Файл **`AGENT_PROMPT.md`** (скачивается на странице **Courts → Import courts**).
3. Файл **`court-import.schema.json`** (там же).

## Шаг 1 — дайте задание ИИ-агенту

Откройте своего ИИ-агента (например, Claude) и передайте ему:
- содержимое файла `AGENT_PROMPT.md`,
- файл `court-import.schema.json`,
- ваш **PDF**.

Агент **ничего не ищет в интернете**: он переносит данные из PDF в формат
импорта и возвращает **один JSON** со всеми кортами.

Если в PDF не хватает обязательных данных для какого-то корта (например, нет
координат), агент **не включит этот корт** в файл, а напишет о нём отдельно
после JSON, под заголовком `COULD NOT VERIFY:`. Это нормально: такой корт можно
добавить позже вручную.

## Шаг 2 — возьмите из ответа только JSON

Агент возвращает JSON в **блоке кода** (рядом есть кнопка «Copy»). Скопируйте
**только этот блок**: либо сохраните его в файл с расширением `.json`
(например, `my-courts.json`), либо просто вставьте в поле на странице импорта.
Текст `COULD NOT VERIFY:` под блоком в файл **не копируйте**: это заметка для
вас, а не часть данных.

## Шаг 3 — загрузите файл в админке

1. Войдите в админ-панель.
2. Перейдите в **Courts → Import courts**.
3. Загрузите `.json`-файл или вставьте JSON в текстовое поле.
4. Нажмите **Check**. Система покажет **проверку (dry run)**: список кортов с
   отметками «всё хорошо», «есть предупреждение» или «есть ошибка». В базу при
   этом ничего не записывается.
5. Если всё выглядит правильно, нажмите **Create**, и корты будут созданы. Если
   хотя бы в одном корте есть ошибка, **не создастся ни один**, пока вы не
   исправите файл и не проверите его снова.
6. Если есть ошибки, нажмите **«Copy errors for the agent»**, вставьте этот текст
   агенту (он вернёт исправленный JSON) и проверьте ещё раз.

Если корт с таким названием уже есть на сайте, система покажет ошибку
**«slug already exists»**: импорт только **создаёт новые** корты и не меняет
существующие.

## Что переносится, а что нет

**Переносится:** название, страна, город, координаты, ссылка Google Maps,
покрытие (surface), тип доступа (access), описание (дословно), метки.

**Не переносится:** фотографии и строки блока «The Essentials» (Booking, Event,
Courts, Court hire, Best time, Website): для них в карточке корта нет полей.
Фото добавляются вручную после импорта.

Также в PDF не указано, крытый ли корт, поэтому агент ставит `Outdoor`
(открытый) и отмечает это в `notes`. Проверьте это перед публикацией.

## Заметки агента (`notes`)

Агент пишет в поле `notes` всё, что стоит проверить: противоречия в самом PDF
(например, «Courts: 23», а в тексте «21 корт»), значения, которые он выбрал или
преобразовал (например, «Artificial grass» → `Grass` или первое из двух
покрытий), и сделанные допущения. Эти заметки **не сохраняются** на сайте, они
нужны только вам. Если что-то не так, исправьте PDF или поле вручную в админке.

## Что важно знать о результате

- **Все импортированные корты создаются как «draft» (черновик)**: они не видны
  посетителям сайта, пока вы не опубликуете их вручную.
- **Все импортированные корты по умолчанию «премиум» (закрытые).** Это значит,
  что точный адрес корта видят только пользователи с платной подпиской, как и
  для остальных кортов на сайте.
- **Фотографий импорт не добавляет.** После импорта откройте каждый новый корт в
  админке и добавьте фото вручную; только после этого можно публиковать.

## ⚠️ Перед публикацией обязательно проверьте координаты на карте

ИИ-агент может ошибиться при переносе цифр. **Прежде чем опубликовать
(сделать видимым) любой импортированный корт**, откройте его в админке и рядом с
координатами нажмите **«Check on map»** (откроется точка на карте). Убедитесь,
что отметка стоит именно на территории этого заведения, а не где-то рядом. Если
отметка выглядит неправильно, исправьте координаты вручную до публикации.
