# Імпорт кортів — інструкція для адміністратора

Ця інструкція — для того, хто додає нові корти через ШІ-агента, без
програмування.

## Що потрібно підготувати

1. **Список назв кортів/закладів**, які потрібно додати (просто список
   назв — більше нічого).
2. Файл **`AGENT_PROMPT.md`** з цієї папки.
3. Файл **`court-import.schema.json`** з цієї папки.

## Крок 1 — дайте завдання ШІ-агенту

Відкрийте свого ШІ-агента (наприклад, Claude або інший) і передайте йому:
- вміст файлу `AGENT_PROMPT.md`,
- файл `court-import.schema.json`,
- ваш список назв кортів.

Агент самостійно знайде інформацію про кожен корт в інтернеті (офіційний
сайт, Google Maps, інші джерела) і поверне **один JSON-файл** з даними про
всі корти.

Якщо агент не зміг надійно перевірити якийсь корт (наприклад, не знайшов
точних координат), він **не включить його** у файл, а напише про це окремо
після JSON, під заголовком `COULD NOT VERIFY:`. Це нормально — такий корт
можна додати пізніше вручну або попросити агента спробувати ще раз з
додатковою інформацією.

## Крок 2 — візьміть із відповіді лише JSON

Агент повертає JSON у **блоці коду** (поруч є кнопка «Copy»). Скопіюйте
**тільки цей блок** — або збережіть його у файл із розширенням `.json`
(наприклад, `my-courts.json`), або просто вставте в поле на сторінці імпорту.
Текст `COULD NOT VERIFY:` під блоком у файл **не копіюйте** — це нотатка для вас,
а не частина даних.

## Крок 3 — завантажте файл в адмінці

1. Увійдіть в адмін-панель.
2. Перейдіть **Courts → Import**.
3. Завантажте ваш `.json` файл або вставте JSON у текстове поле.
4. Спочатку система покаже **перевірку (dry run)** — список кортів із
   позначками: все добре ✅, чи є помилка ❌, чи є попередження ⚠️ — без
   жодного запису в базу даних.
5. Якщо все виглядає правильно — натисніть **"Create"**, і корти буде
   реально створено. Якщо хоч один корт має помилку — **жодний** корт не
   буде створено, доки ви не виправите файл (і не завантажите знову).
6. Якщо є помилки — натисніть **«Copy errors for the agent»**, вставте цей
   текст агенту (він поверне виправлений JSON) і перевірте ще раз.

## Що важливо знати про результат

- **Усі імпортовані корти створюються як "draft" (чернетка)** — вони ще
  **не видно** на сайті відвідувачам, доки ви не опублікуєте їх вручну.
- **Усі імпортовані корти — "преміум" (замкнені), за замовчуванням.** Це
  означає, що точну адресу корту бачать лише користувачі з платною
  підпискою — так само, як і для всіх інших кортів на сайті.
- **Фотографій імпорт не додає.** Після імпорту відкрийте кожен новий корт
  в адмінці та додайте фото вручну — лише після цього можна публікувати.

## ⚠️ Перед публікацією — обов'язково перевірте координати на карті

ШІ-агент може помилитися, особливо з точними координатами. **Перед тим, як
опублікувати (зробити видимим) будь-який імпортований корт**, відкрийте
його в адмінці й біля координат натисніть **«Check on map»** (відкриє точку на
карті) — перевірте, чи дійсно позначка стоїть на території цього закладу, а не
десь поруч чи в іншому місці. Якщо позначка
виглядає неправильно — виправте координати вручну перед публікацією.

## Поширені помилки та що вони означають

| Повідомлення | Що це означає |
|---|---|
| `slug "..." already exists` | Корт із такою ж "адресою-посиланням" (slug) вже є в базі. Найчастіше це означає, що такий корт уже додано раніше. |
| `slug "..." is already used by item N` | У вашому ж файлі два корти отримали однакову посилання-адресу — перейменуйте один із них. |
| `Country name "..." already exists under a different isoCode` | Країна з такою назвою вже є в базі, але під іншим кодом (наприклад, іншим написанням). Перевірте код країни (isoCode). |
| `Unknown tag "..."` | Агент використав тег, якого немає в дозволеному списку. Видаліть цей тег або замініть на дозволений зі списку в `AGENT_PROMPT.md`. |
| `lat/lng of exactly 0,0 is not a valid location` | Координати не були знайдені (нульові) — потрібно вказати реальні координати. |
| "Possible duplicate" (попередження, не помилка) | Схоже, такий корт (за назвою та країною) уже є в базі під іншою адресою-посиланням. Перевірте, чи це справді новий корт, а не дублікат. |
| `429 Too Many Requests` | Забагато спроб імпорту за короткий час. Зачекайте кілька хвилин і спробуйте ще раз. |

Якщо помилка незрозуміла — скопіюйте повідомлення й покажіть розробнику.
